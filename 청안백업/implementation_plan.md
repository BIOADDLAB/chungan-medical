# 🏆 청안메디칼 웹사이트 디자인 표준화 & React 전환 마스터 플랜

사용자님의 피드백을 반영하여, **단순 사진 복제 수준의 디자인에서 탈피**하고, **React(Next.js)** 환경에서 **전역 디자인 시스템**이 적용된 프리미엄 웹사이트로 재탄생시키기 위한 통합 계획입니다.

---

## 🎯 핵심 목표
1.  **디자인 표준화**: 전 페이지의 폰트(자간/행간), 섹션 간격, 컬러 시스템을 1px 단위로 통일.
2.  **유지보수 혁신**: React 컴포넌트 기반으로 헤더, 푸터, 타이포그래피를 통합 관리.
3.  **UI/UX 고도화**: 레퍼런스를 '베끼는' 것이 아니라, 브랜드 가치가 느껴지는 '프리미엄 인터페이스' 구현.

---

## 🏗 1단계: 디자인 시스템 규격 수립 (Design Tokens)

가장 먼저 모든 디자인의 기준이 될 **'디자인 가이드라인'**을 전역에 설정합니다.

### **Typography (타이포그래피)**
-   **국문 폰트**: 'Pretendard' (현존 최강 가독성 폰트) 적용.
-   **영문 폰트**: 'Inter' (기술적이고 세련된 느낌) 적용.
-   **세밀한 조정 (Spacing)**:
    -   **Heading (H1, H2)**: '-0.05em' 자간, '1.2' 행간 → 임팩트와 응집성 강화.
    -   **Body (본문)**: '-0.02em' 자간, '1.7' 행간 → 장시간 읽어도 편안한 가독성.

### **Layout (레이아웃)**
-   **Section Padding**: 모든 섹션의 상하 여백을 '120px' ~ '160px'로 고정하여 시각적 리듬감 부여.
-   **8-Point Grid**: 모든 요소 간의 간격을 8의 배수로 설정하여 수학적 안정감 확보.

---

## 💻 2단계: React (Next.js) 아키텍처 설계

HTML 수동 수정의 한계를 극복하기 위해 **Next.js** 환경으로 전환합니다.

### **컴포넌트 구조**
-   **Header/Footer**: 수정 시 모든 페이지 즉시 반영.
-   **Typography Component**: 전역 스타일 제어.

3. 메인 페이지 -> 제품 상세 6종 -> 문의 페이지 순으로 UI 고도화 작업.
